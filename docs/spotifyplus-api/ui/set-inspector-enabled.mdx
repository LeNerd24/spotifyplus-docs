# UI.setInspectorEnabled()

Enables or disables Spotify Plus's UI inspector.

## Syntax

```ts
SpotifyPlus.UI.setInspectorEnabled(enabled: boolean): Promise<void>
```

## Examples

The following example shows how an extension can use this method.

```ts
await SpotifyPlus.UI.setInspectorEnabled(true);
```

## Parameters

`enabled`

Whether to enable the inspector.

## Returns

`Promise<void>`

## Remarks

Use the inspector to examine Spotify's live UI. See [captureHierarchy()](./capture-hierarchy.mdx) for a structured snapshot.
