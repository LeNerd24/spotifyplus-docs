# UpNext.getExpanded()

Requests a larger snapshot of upcoming context tracks.

## Syntax

```ts
SpotifyPlus.UpNext.getExpanded(limit?: number): Promise<ExpandedUpNextSnapshot>
```

## Examples

The following example shows how an extension can request more upcoming tracks.

```ts
const snapshot = await SpotifyPlus.UpNext.getExpanded(100_000);
console.log(snapshot.next.length, snapshot.completeness);
```

## Parameters

`limit`

An integer from 1 to 100,000. Defaults to 10,000.

## Returns

`Promise<ExpandedUpNextSnapshot>`

The ordinary snapshot fields plus `snapshotId`, `contextUri`, `requestedLimit`, and `completeness`. See [API result types](../../types/api-types.md#expandedupnextsnapshot).
