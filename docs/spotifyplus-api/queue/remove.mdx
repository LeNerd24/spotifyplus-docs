# Queue.remove()

Removes a song from the queue.

## Syntax

<CodeBlock language="ts">
  <span style={{ display: 'inline' }}>SpotifyPlus.Queue.remove(index: number): void</span>
</CodeBlock>

## Examples

The following example shows how an extension can remove the next queued occurrence without affecting the current song.

```ts
// Remove the next queued occurrence without affecting the current song.
const snapshot = SpotifyPlus.Queue.get();
const next = snapshot.next[0];
if (!next) return;

try {
  SpotifyPlus.Queue.remove(0);
  SpotifyPlus.toast('Removed from queue');
} catch (error) {
  // The queue may have changed since this snapshot was read.
  console.warn('Queue changed. Please fetch it again', error);
}
```

## Parameters

`index`

<Badge>number</Badge> <Badge variant="danger">Required</Badge>

The index in `snapshot.next` to remove.
