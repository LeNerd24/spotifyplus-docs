# Queue.add()

Adds one or more song to the queue.

## Syntax

<CodeBlock language="ts">
  <span style={{ display: 'inline' }}>SpotifyPlus.Queue.add(items: <a href="/docs/types/spotify-uri-input">SpotifyUriInput</a> | <a href="/docs/types/spotify-uri-input">SpotifyUriInput</a>[]): void</span>
</CodeBlock>

## Examples

The following example shows how an extension can find a track and put it at the end of the queue.

```ts
// Find a track and put it at the end of the queue.
const results = await SpotifyPlus.Search.search('Blinding Lights');
const track = results.items.find(item => item.uri.startsWith('spotify:track:'));
if (!track) return;

SpotifyPlus.Queue.add(track.uri);
SpotifyPlus.toast(`Queued ${track.text}`);
```

## Parameters

`items`

<Badge>SpotifyUriInput | SpotifyUriInput[]</Badge> <Badge variant="danger">Required</Badge>

One URI or an array of URIs to queue.
