# Queue.move()

Moves a song in the queue.

## Syntax

<CodeBlock language="ts">
  <span style={{ display: 'inline' }}>SpotifyPlus.Queue.move(index: number, toIndex: number): void</span>
</CodeBlock>

## Examples

The following example shows how an extension can make the second upcoming song play next.

```ts
// Make the second upcoming song play next.
const snapshot = SpotifyPlus.Queue.get();
if (snapshot.next.length < 2) return;

try {
  SpotifyPlus.Queue.move(1, 0);
  SpotifyPlus.toast('Moved song to the front of the queue');
} catch (error) {
  // Get a fresh snapshot before trying another reorder.
  console.warn('Queue changed', error);
}
```

## Parameters

`index`

<Badge>number</Badge> <Badge variant="danger">Required</Badge>

The index in `snapshot.next` to move.

`toIndex`

<Badge>number</Badge> <Badge variant="danger">Required</Badge>

The item’s final position in the upcoming queue.
